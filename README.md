# 주유소 전주기 데이터 워크스페이스

대한민국 주유소의 입지 검토부터 폐업·사후관리까지 단계별 담당기관, 수집 항목과 공식 사이트를 안내하는 정적 웹 앱입니다.

## 실행 및 검증

Python 3와 Node.js 18 이상을 사용합니다. 외부 패키지, DB, API 키 설치는 필요 없습니다.

```sh
cd /workspace/desktop-tutorial
npm test
npm start
```

8000 포트에서 실행합니다. 종료는 Ctrl+C입니다. 클라우드 작업에는 이미 격리된 체크아웃이 있으므로 별도의 Git worktree를 만들 필요가 없습니다.

## 실제 인허가 자료 조회

LOCALDATA 또는 공공데이터포털에서 주유소 인허가 CSV를 내려받아 화면에서 선택하세요. 사업장명 열이 필요하며 상세영업상태명/영업상태명, 도로명전체주소/소재지전체주소, 인허가일자, 폐업일자를 표시합니다. 인코딩은 UTF-8 또는 EUC-KR을 선택합니다. 30MB 이하 파일을 지원하며 데이터는 브라우저 메모리에서만 처리합니다. 검색·상태 필터·페이지 이동·초기화를 제공합니다. 새로고침하면 업로드 자료가 사라집니다.

자동 다운로드, 실시간 가격 API, 기관별 비공개 문서 연계는 구현되어 있지 않습니다. 예시 데이터를 실제 자료로 표시하지 않습니다. 공공 사이트는 현재 클라우드 네트워크에서 접근이 차단되어 원본 다운로드 및 최신 법령 내용은 검증하지 못했습니다. 표시된 절차는 검토 가이드이며 관할기관에서 적용 요건과 최신 기한을 확인해야 합니다. 인허가 관리번호와 오피넷 ID 연결은 별도 검증이 필요합니다.

외부 출처: LOCALDATA (localdata.go.kr), 공공데이터포털 (data.go.kr), 오피넷 (opinet.co.kr), 한국석유관리원 (kpetro.or.kr), 정보공개포털 (open.go.kr), 국가법령정보센터 (law.go.kr), 홈택스 (hometax.go.kr).


## 포함된 실제 자료와 자동 배포

사용자가 제공한 `산업통상부_전국 주유소 등록현황_20251231.csv`를 `initial-data.js`로 변환하여 첫 실행에 자동 표시합니다. 총 9,377행이며 2015-01-02~2025-12-31의 변동 이력입니다. 휴업 5,643건, 신규등록 823건, 폐업 2,557건, 등록취소 181건, 신규 173건입니다. 행 수는 고유 주유소 수나 현재 영업 중 주유소 수가 아닙니다. `변동사유발생연월일`은 변동 발생일로 표시하며 인허가일이나 폐업일로 임의 복사하지 않습니다.

`npm run build`는 `dist/`에 정적 사이트와 PC용 `station-lifecycle.html`을 생성합니다. PC용 HTML은 별도 서버 없이 열 수 있습니다.

GitHub Pages 자동 배포 구성은 `.github/workflows/pages.yml`입니다. 저장소 Settings → Pages → Source에서 GitHub Actions가 선택되어 있어야 합니다. main 브랜치에 게시되거나 workflow_dispatch가 실행되면 테스트·빌드 후 배포합니다. 현재 클라우드에서 Git 읽기는 가능하지만 GitHub API는 Forbidden이므로 Pages 활성화·배포 및 공개 URL은 검증하지 못했습니다. 환경 게시와 GitHub Pages 웹사이트 배포는 별개입니다.


## 추가 인허가 자료

사용자가 올린 `자원환경_석유판매업.csv`(CP949) 29,635행을 추가했습니다. 기본은 업태구분명 주유소 18,723행이며 출처·업종·상태별 조회가 가능합니다. 기존 변동 이력과는 병합하지 않습니다. 영업상태명과 상세영업상태명을 구분합니다. 화면에 필요한 열만 내장했고 전화번호·좌표는 포함하지 않았습니다. 관리번호는 문자열을 보존합니다. 테스트는 5개입니다.
